Data Flow

1. User Says: "Alexa, go north"
2. Alexa: Recognizes speech as Intent, extracts "north" parameter
3. Lambda: Receives request, finds "north" link in current room
4. Lambda: Updates player position, generates speech response
5. Alexa: Converts response to speech and plays to user

Module 4

Voice Interaction Design

Good voice design makes players feel like talking to a person, not operating a machine.

Intent Definition (en-US.json)

Voice commands defined for the Go Intent:

{ "name": "Go", "samples": [ "go {direction}", // generic format "run {direction}", // synonyms "walk {direction}", // synonyms "explore {direction}", // exploration "{direction}" // direct direction ], "slots": [{ "name": "direction", "type": "LIST_OF_DIRECTIONS" }] }

Basic Directions

north, south, east, west, up, down, in, out, left, right

Location Words

desk, window, door, stairs, elevator, corridor, hall, basement

Quiz
How does Alexa understand "run east"?
Matches Go Intent with direction slot = "east"
Creates a new "Run" Intent
Cannot understand, asks user to repeat

Customize Your Adventure

Story content is completely decoupled from game logic. To create your own adventure:

1. Download Twine 2
2. Create your story (replace "Escape the Office.html")
3. Modify invocation name in skill.json
4. Deploy and enjoy!
